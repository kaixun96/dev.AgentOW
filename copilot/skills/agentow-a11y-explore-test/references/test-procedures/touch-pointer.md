# Touch and pointer

1. Verify target size and spacing for actionable controls.
2. Test cancellation, drag alternatives, multipoint/path gesture alternatives, and pointer-down
   behavior.
3. Confirm visible labels match accessible names.
4. Test orientation/motion input alternatives when device motion is supported.
5. When Voice Access is requested, run this category as `serial-real-at`; preserve recognized
   commands, result JSON, non-silent audio, capture state, overlay attribution, and screenshot.
6. Execute representative pointer cancellation, target activation, drag alternative, and gesture
   alternative paths where applicable; target inventory alone is insufficient.

Record target rectangles, input method, alternative path, and screenshots.
