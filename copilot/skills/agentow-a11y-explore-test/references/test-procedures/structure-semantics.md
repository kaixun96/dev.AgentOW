# Structure and semantics

1. Capture the live heading outline and verify levels from actual parent/sibling context.
2. Inventory main/navigation/search/banner/contentinfo landmarks and detect missing or duplicate
   labels.
3. Verify lists, tables, groups, regions, dialogs, and form relationships use native or equivalent
   semantics.
4. Confirm DOM and accessibility reading order preserve meaning.
5. Check link/button purpose and page title.

Capture the accessibility facts and a full-page context screenshot. Do not infer hierarchy from
visual size alone.
